TAMARIND BUSINESS MANAGER - MOBILE APPLET

This is an installable Progressive Web App (PWA).

IMPORTANT:
A PWA must be served from an HTTPS website to install and use offline service-worker caching.
Opening index.html directly from the phone's file manager will run the calculator in a browser,
but installation and offline caching may not be available.

EASIEST USE:
1. Upload the contents of this folder to an HTTPS static host (for example GitHub Pages).
2. Open the hosted link in Chrome on Android.
3. Tap the three-dot menu > Add to Home screen or Install app.
4. Launch it from the new home-screen icon.

All calculator features and both packet recipes are included.
Production records are stored locally in the browser on that device. Export CSV backups regularly.
